About

Real-ESRGAN is trained on synthetically degraded images, so it removes blur, noise and JPEG artifacts while it enlarges. The photo models suit real-world images; the illustration model keeps line art and flat color clean.

Large images are processed in overlapping tiles, so memory stays bounded regardless of input size. Uploaded images are processed in memory and not stored.
